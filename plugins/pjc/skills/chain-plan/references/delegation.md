# 판정 위임 (`pjc:chain-plan`)

> `../SKILL.md` 「답하는 기준」이 워커 `plan.md` 승인 요청의 봉투 대조가 어긋날 때만 이 파일을 연다. 봉투의 세 대조(task 줄·`승인 필요 항목`·`DB 변경`)와 사용자 몫 넷의 정본은 `../SKILL.md`「답하는 기준」이다.

## 봉투 밖 승인 요청

- **하나라도 어긋나면 봉투 밖이다 — 회피 설계부터 지시한다.** 봉투의 task 줄 대조가 넘침이면 그 task 없이 목표가 되는지 보고 되면 `E: <그 task 를 뺀다> (코디네이터 판정 — <근거>)`, 안 되면 사용자 몫 ③ 요청 범위 변경으로 사용자에게 넘긴다. task 줄 대조가 누락이면 `E: <빠진 항목> 을 넣거나 빠진 근거를 적는다 (코디네이터 판정 — <근거>)`. `승인 필요 항목`·`DB 변경` 대조가 어긋나면 사용자 몫(`../SKILL.md` 넷)이 아닌 한 어긋난 항목이 생기지 않는 설계가 있으면 `E: <회피 설계> (코디네이터 판정 — <근거>)`, 없을 때만 `Y (코디네이터 판정 — <근거>)` — 워커가 스스로 고른 설계가 만든 승인 항목은 대개 다른 설계로 사라진다(`../../plan/SKILL.md` Step 4). 봉투 밖이라는 사실만으로 사용자에게 넘기지 않는다.
