# 화면 가리기 스크립트 근거 (`skills/implement/scripts/screen-cover.ps1`)

> 호출자는 이 파일을 읽지 않는다 — 언제·누가 부르고 출력을 어떻게 읽는가는 `skills/SCREEN-COVER.md` 가 정본이다. 이 파일은 스크립트를 고칠 때 연다.

## 잠금

보유자 기록을 고치는 동안 잠금 파일을 `FileShare.None` 핸들로 연다. 잠근 프로세스가 죽으면 OS 가 그 핸들을 닫으므로, 다음 호출이 남은 잠금 때문에 영영 막히지 않는다. 잠금 표지 파일을 만들고 지우는 방식은 프로세스가 중간에 죽으면 표지가 남아 수동 정리가 필요하다.

## 앱 꺼짐 판정

꺼짐은 `status --json` 의 `appRunning:false` 하나로 가른다. 오류 코드(`runtime_unavailable`·`app_not_running`)는 「앱이 꺼졌다」와 「앱이 아직 응답하지 않는다」를 가르지 못한다. 오류 코드로 꺼짐을 판정하면 일시 오류에도 기록을 지우고, 그러면 걷은 모니터를 다시 덮지 못한다. 꺼짐일 때 기록을 지우는 이유는 `skills/SCREEN-COVER.md` 「언제 끄고 켜는가」 가 정본이다.
