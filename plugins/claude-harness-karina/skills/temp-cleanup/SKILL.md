# 임시 폴더 정리

`%TEMP%\karina-plugin\` 아래 항목을 보이고 **사용자가 고른 것만** 지운다. 폴더 배치와 무엇이 자동으로 지워지는지는 `../TEMP-FILES.md` 가 정한다 — 백업 두 폴더(`backup\`·`worktree-backup\`)는 자동 정리 대상이 아니라 여기서만 지운다. 목록과 삭제·거부 판정은 `scripts/temp_cleanup.py` 가 하고, 이 문서는 사용자 게이트를 맡는다. 출력 형식·거부 조건·종료 코드의 정본은 그 스크립트의 모듈 docstring 이다.

## 절차

1. **목록** — `python "<이 SKILL.md 의 폴더>/scripts/temp_cleanup.py" list` 를 돌린다.
2. **표를 보인다** — 하위 폴더별로 묶어 항목·크기·수정 시각을 보이고 폴더마다 합계를 붙인다. `사용 중일 수 있음` 표시는 실행 중인 체인의 잠금일 수 있어 스크립트가 지우지 않는다고 한 구 붙인다. 사용자는 폴더째 · 특정 날짜보다 오래된 것 · 개별 항목 중에서 고른다. 고르지 않으면 지우지 않고 끝낸다.
3. **삭제 계획을 보이고 한 번 승인받는다** — 고른 경로로 `remove --dry-run <경로>...` 를 돌려 `WOULD-REMOVE`·`REFUSED` 줄을 그대로 보인다. 백업은 원본이 사라진 뒤의 유일한 사본일 수 있어 지우면 되살릴 수 없다고 알린다. 승인 없이 4번으로 가지 않는다.
4. **삭제** — 승인받은 경로 그대로 `remove <경로>...` 를 돌린다. 경로를 바꾸거나 늘리려면 3번으로 돌아간다.
5. **보고** — `RESULT` 줄, 지운 경로와 크기 합계, `REFUSED`·`FAILED` 경로와 사유.

## 하지 않는 것

- **`rm`·`Remove-Item` 을 직접 치지 않는다** — 루트 밖·루트 자체·실행 중 잠금을 거부하는 판정은 스크립트 안에만 있다. 모델이 조립한 경로로 직접 지우면 되돌릴 수 없는 오삭제가 된다.
- **`karina-plugin` 밖의 임시 파일은 다루지 않는다** — Karina 앱의 `karina-statusline-*`·Claude Code 의 `%TEMP%\claude\` 는 각자의 도구가 관리한다.
- **`FAILED` 를 다른 수단으로 재시도하지 않는다** — 다른 프로세스가 파일을 쥐고 있으면 그 프로세스를 끝낸 뒤 다시 돌리라고 보고한다.
