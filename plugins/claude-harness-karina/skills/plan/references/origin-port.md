# 원본 이식 plan

> `interview.md` 2-3 에서 요구 원문·답이 원본을 그대로 옮기라고 하거나 `AGENTS.md` 가 `UI 재구현 기준 소스` 를 선언했을 때 읽는다. 실행 중 규칙은 `../../implement/references/code-style.md`「원본을 옮길 때」 다.

## 원본 이식

- **요구 원문·답이 원본을 그대로 옮기라고 하면(원본대로·원본 그대로·원본 기준) 묻지 않고 Goal 에 `> 원본 기준: <원본 위치>` 줄을 쓴다 — 이 줄이 선언 없이도 원본 이식 규칙을 켠다(`check-plan` 이 모든 task 에 원본 줄을 요구하고 빈 값은 `origin-basis`)** — 선언 줄은 사용자가 존재를 모르는 `AGENTS.md` 항목이라, 요구로 켜지지 않으면 원본대로 요구가 Goal 문장에만 남고 실행자가 원본과 다른 선택을 스스로 닫는다(2026-11-25 사용자 관측).
- **`AGENTS.md` 에 선언이 없으면 `interview.md`「후보 목록」 의 함께 고칠 곳에 선언 줄 추가(서식 `../../AGENTS-BOUNDARY.md`「생성물 골격 (정본)」)를 권장 `포함` 으로 올린다** — 다음 계획부터는 요구를 다시 말하지 않아도 화면 task 가 원본 줄을 갖는다.
- **task 를 나누기 전에 범위 안 원본 파일 전량을 `## 원본 대응` 표(원본 경로 | `T<N>`·`제외 — <사유>`)에 올리고 Log `원본 전량 <N>` 행으로 받친다. 선언 레포는 화면 task, `> 원본 기준:` plan 은 모든 task 에 `**원본**` 줄을 두고 경로와 조각(원본의 그리는 함수로 센다)마다 옮김·미룸·이탈(Log `이탈 T<N>` 행)을 적는다. 원본 없는 task 는 Files 줄에 `[원본 없음 — <사유>]` 를 단다(`check-plan` `origin-*`)** — 표가 없으면 어느 task 에도 들지 않은 원본 파일이 승인 뒤 구현 중에야 드러난다.
