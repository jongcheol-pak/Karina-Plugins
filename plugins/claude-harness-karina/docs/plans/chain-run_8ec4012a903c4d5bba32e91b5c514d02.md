- 골든 케이스를 더하면 기준선 세 곳을 **2218** 에서 함께 올린다 — 값은 무인자 실행의 `결과: N/N` 으로 맞춘다
- `implement/SKILL.md` 여유 43자 · `agents/plan-reviewer.md` 여유 35자 · `agents/completion-reviewer.md` 여유 2자
- 새 주석이 막히면 차단 메시지의 안내(보존 경로 등록 · rationale `.md` 먼저)를 따른다 — 문서가 정본으로 지정하지 않은 머리·구획 주석은 쓰지 않는다
- 역슬래시나 삭제 명령 꼴이 든 치환은 Bash heredoc 이 아니라 Write 로 만든 스크립트 파일이나 Edit 로 한다 · 커밋 본문에 역슬래시가 들면 `git commit -F <파일>`
- Temp 의 픽스처 `plan.md` 는 셸 명령으로 쓰지 않는다 — Write 도구로 쓰거나 스크립트 파일 안에서 쓴다
- 차단 hook 에 「명령 문자열을 읽어 안전하면 뺀다」 는 면제를 넣지 않고, 차단 판정의 정규식을 요청 없이 갈아 끼우지 않는다(`docs/conventions.md` 「hook 검사·차단」 2026-11-20)
- 완료 리뷰에 넘기는 전사 요약은 `digest_transcript.py --session <세션 ID>` 로 만든다 — 고정 경로는 병행 세션이 덮어쓴다(이 회차 10차 리뷰가 다른 세션 요약을 받았다)
- plan 1·2 의 제약은 그대로다
